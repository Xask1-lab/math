# Математика у клітинку

**▶ Відкрити й встановити: https://xask1-lab.github.io/math/**

Калькулятор з рівняннями й нерівностями, графіки функцій і уроки з тестами — від 1 класу до інституту. Працює в браузері, встановлюється як застосунок (PWA) і працює без інтернету.

## Можливості

- **Калькулятор** — дроби та мішані числа, степені, корені, тригонометрія, логарифми. Кілька вікон з назвами, рядки, змінні (`a=5`).
- **Рівняння, нерівності, системи** — лінійні, квадратні та інші; два сусідні рядки з `x` і `y` розв’язуються як система. Кнопка «Розв’язок» показує кроки.
- **Одиниці та константи** (кнопка ⇄) — перетворення довжини, маси, тиску, енергії, температури, префікси; фізичні константи.
- **Графіки** — до 5 функцій, нулі, перетини, максимуми й мінімуми, таблиця значень.
- **Уроки** — понад 60 тем з теорією, генератором завдань, малюнками до геометрії, розв’язаними прикладами, тестами й історією. Пошук, фільтри «слабкі / засвоєні», аркуш завдань для друку.
- **Рівні та конструктор тестів** — «Легкий / Середній / Складний / Мішаний», а для кожної теми галочками можна вибрати види завдань (355 видів у 64 темах); у тесті теми комбінуються.
- **Резервна копія** (кнопка ⚙) — збереження й відновлення всіх даних, вибір теми оформлення.

## Встановлення на телефон чи комп’ютер

1. Відкрийте сторінку програми в браузері.
2. **Android / Chrome / Edge:** меню ⋮ → «Встановити застосунок» (або «Додати на головний екран»).
3. **iPhone / iPad (Safari):** кнопка «Поділитися» → «На екран “Додому”».

Після першого відкриття програма працює офлайн. Дані (вікна калькулятора, історія тестів) зберігаються лише в цьому браузері.

## Файли

| Файл | Призначення |
|---|---|
| `src/math.html` | **джерело** програми (HTML, CSS, JS в одному файлі); на початку скрипта — нотатки для розробки, версія та історія змін |
| `build.py` | збирає `index.html` із джерела |
| `index.html` | готова сторінка для сайту (не редагувати вручну) |
| `manifest.webmanifest` | опис застосунку для встановлення |
| `sw.js` | сервіс-воркер — офлайн-кеш |
| `icons/` | іконки застосунку |

## Як оновлювати

1. Змініть `src/math.html`; підніміть `APP_VER` і допишіть рядок в «ІСТОРІЮ ВЕРСІЙ» на початку скрипта.
2. `python3 build.py` — збере `index.html`.
3. Збільште `VERSION` у `sw.js` (напр. `math-v6`), щоб у користувачів підтягнулась нова версія.

Поточна версія програми показана в «Налаштуваннях» (кнопка ⚙).
